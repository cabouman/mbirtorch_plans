# mbirtorch_plans

Plans, findings and experiment scripts for the [mbirtorch](https://github.com/cabouman/mbirtorch)
project (Bouman group, Purdue).  The plans under `plans/` are the record; the scripts under
`plans/experiments/` are what produced the numbers in them.

New to the group's clusters?  Read [`.claude/cluster_use.md`](.claude/cluster_use.md) (how we
use gautschi and gilbreth, written for Claude sessions run by any member of the group) and
[`.claude/gpu-resources.md`](.claude/gpu-resources.md) (what the group has bought and how to
get access).
